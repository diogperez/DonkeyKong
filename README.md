Donkey-Kong Clone – OOP 2023/24

This project is a Java-based remake of the classic Donkey Kong arcade game, developed for the Object-Oriented Programming course at ISCTE-IUL.
It features multiple levels with increasing difficulty, interactive elements like traps, weapons, and power-ups, and a high-score system that tracks your best performances.
The focus of the project was to apply core object-oriented programming concepts.
