Donkey-Kong Clone – OOP 2023/24

This project is a Java-based remake of the classic Donkey Kong arcade game, developed for the Object-Oriented Programming course at ISCTE-IUL.

It features multiple levels with increasing difficulty, interactive elements like traps, weapons, and power-ups, and a high-score system based on completion time.

Gameplay includes dynamic difficulty: enemy attack frequency increases with each level, and room transitions retain character attributes.

Additional features include: 
- Hammer (activated with 'H') that defeats Donkey Kong on contact
- Fireball (activated with 'F') that damages Donkey Kong
